# AI Usage

**Assistant / Model:** Google Antigravity (Powered by Gemini)  
**Project:** Expedition Outpost (Orange Home)

---

*I used AI Only strictly for the following tasks in this project:*

1. **Mesh Repair & STL Conversion:**  
   Fixed intersecting meshes and non-manifold geometry across the raw `.blend` files to convert and export a clean, watertight 3D-printable `.stl` file.

2. **Render Generation & Presentation:**  
   Set up camera framing and generated renders in Blender's Workbench engine across two sleek styling themes:
   * **Solid Random Components:** Pastel color-coding across each individual piece, giving it a sleek collectible toy / Lego look.
   * **Colorless Architectural White:** Clean matte finish highlighting pure geometry, depth, and shadows.

3. **Documentation Layout & Grammar Polish:**  
   I first hand-typed the raw journal notes and README myself; AI then helped organize everything into clean Markdown formats, fix typos, and polish grammar also ai helped me make Guide.md(with all details).
